# 阶段 4: 仿写 Skill 构造

## 目标

将 STYLE_PROFILE.md 转化为一个独立的、可被 agent 直接调用的 SKILL.md。

## 构造规则

### Frontmatter

```yaml
---
name: <author-slug>
description: |
  模仿<作者名>的写作风格创作故事、分析人物。
  触发关键词：<关键词列表>
  不适用于：<反场景列表>
---
```

### 正文结构（参照 templates/SKILL.template.md）

完整模板见 `templates/SKILL.template.md`，核心结构如下：

```markdown
# <作者名>写作风格指南

## 核心思想体系
（从母题维度提取：世界观、哲学基础、价值取向）
  - 世界观核心设定（如适用：修行体系、社会规则、超自然设定等）
  - 人生观与价值观
  - 处事哲学

## 写作风格特点
（从六维档案浓缩为 4-8 条，每条含要点和示例）

## 典型写作范式
（从签名维度提取，含 2-3 个示例段落——直接从原文摘取）

## 常见元素与设定
（从签名维度和母题维度提取的高频元素：门派/组织、法器/道具、功法/术语、重要地点等）

## 写作注意事项
（从反模式提取，每条含"为什么不要这样做"）
```

### 内容映射

| SKILL.md 段落 | 来源维度 | 提取方式 |
|---|---|---|
| 核心思想体系 | 母题 (T) | 哲学体系 + 世界观 + 价值取向 |
| 写作风格特点 | 韵律 (P) + 词汇 (L) + 叙事 (N) + 对话 (D) | 每个维度选 1-2 条最核心的 |
| 典型写作范式 | 签名 (S) | 签名句式 + 签名场景 + 原文示例 |
| 写作注意事项 | 签名 (S) 反模式 | 所有反模式 + 为什么 |

### 质量检查

生成 SKILL.md 后，检查:
1. ✅ Frontmatter 的 description 是否包含明确的触发条件
2. ✅ 是否有至少 2 段原文示例（≤200 字/段）
3. ✅ 是否有至少 3 条反模式
4. ✅ 每条风格特点是否可操作（不是抽象描述）
5. ✅ 整体是否能让一个没读过原作的 agent 理解如何仿写

## 后续使用

生成的 SKILL.md 可以:
1. 直接复制到 `.claude/skills/<author-slug>/SKILL.md` 作为独立 skill 使用
2. 用户通过 `/author-slug` 触发，agent 将按照风格指南创作
3. 建议用 `/novel-evaluator-1.0.0` 对仿写结果评分，验证风格还原度
